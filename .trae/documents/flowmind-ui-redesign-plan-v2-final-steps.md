## Step 19: 优化任务中心 `/tasks`

**文件**: `app/tasks/page.tsx` [重写]

**现状问题**:
- 没有顶部概览指标
- 任务卡片缺少关联工作流标识
- 没有时间线视图
- 缺少步骤执行日志展开

**优化后布局**:
```
┌─────────────────────────────────────────────────┐
│ 顶部指标 (4个 AnimatedNumber)                     │
│ 总任务 156 | 运行中 2 | 已完成 148 | 失败 6        │
├─────────────────────────────────────────────────┤
│ 搜索框 + 筛选 + 视图切换 [列表] [时间线]           │
├─────────────────────────────────────────────────┤
│ Tabs: [全部] [运行中] [已完成] [待处理]            │
├─────────────────────────────────────────────────┤
│ 任务卡片列表 / 时间线视图                          │
│                                                  │
│ 每张卡片:                                         │
│ - 标题 + 状态Badge + 优先级Badge + 工作流Badge     │
│ - 描述 (2行截断)                                  │
│ - 时间 + Agent + 步骤进度 + 输出摘要               │
│ - 点击展开: 步骤执行日志 (时间线样式)               │
│   ┌─ ✓ 数据采集  08:05-08:30  ops-001            │
│   ├─ ✓ 趋势分析  08:30-09:15  ops-001            │
│   ├─ ● 竞品对比  09:15-...    ops-001  [运行中]   │
│   ├─ ○ 利润计算  待执行       ops-001             │
│   └─ ○ 报告生成  待执行       dispatch-001        │
└─────────────────────────────────────────────────┘
```

**具体实现**:

1. **顶部指标栏**: 4个数据指标卡
   - 总任务 (156) | 运行中 (2, 琥珀色闪烁) | 已完成 (148, 绿色) | 失败 (6, 红色)
   - 使用 `AnimatedNumber` + 状态色彩

2. **工作流 Badge 映射**: 根据任务标题/描述自动识别关联工作流
   ```typescript
   const workflowMapping = [
     { keyword: "选品", label: "选品工作流", color: "var(--wf-product)" },
     { keyword: "广告", label: "AI广告", color: "var(--wf-ad)" },
     { keyword: "Listing", label: "AI上架", color: "var(--wf-listing)" },
     { keyword: "合规", label: "风控", color: "var(--wf-competitor)" },
     { keyword: "支付", label: "风控", color: "var(--wf-competitor)" },
   ];
   ```

3. **视图切换**: 列表视图 / 时间线视图
   - 列表视图: 现有卡片样式，增加工作流 Badge
   - 时间线视图: 按时间排列的垂直时间线
     - 左侧时间轴线 (垂直连接线 + 时间节点)
     - 右侧任务摘要卡片
     - 运行中任务节点带脉冲动画

4. **步骤执行日志**: 点击任务卡片展开
   - 左侧连接线 (已完成=实线绿色, 运行中=脉冲琥珀色, 待执行=虚线灰色)
   - 每步: 状态图标 + 步骤名 + 时间范围 + Agent名 + 状态Badge
   - 有 output 的步骤显示输出摘要

5. **搜索和筛选**: 保留现有搜索 + 增加优先级筛选下拉

## Step 20: 优化记忆系统 `/memory`

**文件**: `app/memory/page.tsx` [重写]

**现状问题**:
- 没有搜索功能
- 缺少使用频率指标
- 创建/修改时间显示不完整
- 概览指标区不够突出

**优化后布局**:
```
┌─────────────────────────────────────────────────┐
│ 标题 + 描述                                       │
├─────────────────────────────────────────────────┤
│ 概览指标 (3个 data-grid 卡片)                      │
│ 预设区 2条 | 开发区 2条 | Prompt区 2条              │
│ 每个: 图标 + 区名 + 记录数 + 验证率 + 最近更新       │
├─────────────────────────────────────────────────┤
│ 搜索框 + 类型筛选 + 排序选择                        │
├─────────────────────────────────────────────────┤
│ Tabs: [全部(6)] [预设区(2)] [开发区(2)] [Prompt区(2)]│
├─────────────────────────────────────────────────┤
│ 记忆条目卡片 (增强版)                               │
│ - 标题 + 版本Badge + 类型Badge + 验证状态           │
│ - 内容摘要                                         │
│ - 标签列表                                         │
│ - 新增: 使用频率指标 (调用次数 + 迷你sparkline)      │
│ - 新增: 创建时间 + 最后修改时间 (更突出)             │
│ - 新增: 关联工作流标签                              │
└─────────────────────────────────────────────────┘
```

**具体实现**:

1. **增强概览指标**: 3个 data-grid 样式卡片
   - 每个: 大字记录数 + 区名 + 验证率百分比 + 最近更新时间
   - 添加颜色编码: 预设区=emerald, 开发区=sky, Prompt区=amber

2. **搜索功能**:
   - 搜索框: 按标题/内容/标签过滤
   - 类型筛选: 全部/script/code/prompt/skill
   - 排序: 最近更新/创建时间/版本号

3. **增强记忆条目卡片**:
   - 新增 `usageCount` 模拟数据 (内联)
   - 显示使用频率: "本月调用 47 次" + 趋势迷你sparkline
   - 创建时间: `2026-04-15`
   - 最后修改: `2026-05-01` (相对时间 "8天前")
   - 关联工作流: Badge标签 (如 "选品工作流")
   - 保留: 版本、类型、标签、验证状态

4. **视觉优化**:
   - 概览卡片使用 data-grid 样式 (带背景色、更大数字)
   - 条目卡片左侧增加区色带 (2px色条)
   - 待验证条目增加微弱脉冲边框

## Step 21: 优化自进化 `/evolution`

**文件**: `app/evolution/page.tsx` [重写]

**现状问题**:
- 没有进化前后对比
- 缺少历史趋势 sparkline
- 流水线进度动画单一
- 缺少 AnimatedNumber

**优化后布局**:
```
┌─────────────────────────────────────────────────┐
│ 标题 + 描述                                       │
├─────────────────────────────────────────────────┤
│ 概览指标 (4个 AnimatedNumber)                      │
│ 进化项目 4 | 已复用 1 | 进行中 3 | 成功率 25%      │
├─────────────────────────────────────────────────┤
│ 进化流水线 (增强版)                                │
│ [识别] ──→ [生成] ──→ [测试] ──→ [审查] ──→ [复用]  │
│  连接线: 实线绿色=已完成, 脉冲琥珀=进行中, 虚线=待定  │
│  每个阶段节点下方: 进度百分比 + 项目数               │
├─────────────────────────────────────────────────┤
│ 历史趋势 (Sparkline): 近6个月进化成功数             │
├─────────────────────────────────────────────────┤
│ 进化记录列表 (增强版)                               │
│                                                  │
│ 每条记录:                                         │
│ - 阶段图标 + 标题 + 状态Badge + 阶段Badge          │
│ - 描述                                            │
│ - Agent + 时间信息                                │
│ - 指标面板 (accuracy/latency/coverage)             │
│ - 新增: 成功记录显示"优化前 vs 优化后"对比          │
│   ┌─ 优化前 ──────┬─ 优化后 ──────┐               │
│   │ 准确率: 72%   │ 准确率: 92%   │  ← 双色进度条  │
│   │ 延迟: 450ms   │ 延迟: 120ms   │               │
│   │ 覆盖率: 60%   │ 覆盖率: 85%   │               │
│   └───────────────┴───────────────┘               │
│ - 进行中记录: 进度条动画 (脉冲流动效果)              │
└─────────────────────────────────────────────────┘
```

**具体实现**:

1. **概览指标**: 4个 AnimatedNumber 卡片
   - 进化项目总数 / 已成功复用 / 进行中 / 成功率
   - 颜色编码: 总数=默认, 复用=emerald, 进行中=amber, 成功率=indigo

2. **增强进化流水线**:
   - 连接线改为: 绿色实线(已完成段) → 琥珀色脉冲(进行中段) → 灰色虚线(待定段)
   - 每个节点下方增加文字: "3/5 已完成" 或进度百分比
   - 进行中阶段的图标增加脉冲动画 (ring animation)

3. **历史趋势 Sparkline**:
   - 模拟数据: 近6个月的进化成功数
   - `const evolutionTrend = [2, 3, 1, 4, 3, 5];` (12月-5月)
   - 使用 Sparkline 组件显示，标注最大值

4. **优化前后对比** (仅成功记录):
   - 双列对比面板: 左=优化前(灰色调) | 右=优化后(绿色调)
   - 三个指标使用双色进度条: 前=灰色进度条, 后=彩色进度条
   - 数字使用 AnimatedNumber 增加视觉冲击
   - 在 mock-data 中增加 `beforeMetrics` 字段

5. **进行中记录增强**:
   - 进度条增加流动动画 (CSS animation)
   - 显示 "预计完成时间" (基于开始时间和当前阶段)
